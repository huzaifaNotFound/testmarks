CHAPTER 1: RELATIONS AND FUNCTIONS
A relation R from A to B is a subset of A x B. A relation on A is reflexive if aRa for all a in A, symmetric if aRb implies bRa, transitive if aRb and bRc imply aRc. An equivalence relation is reflexive, symmetric and transitive; equivalence classes partition the set. A function f: A -> B is one-one (injective) if f(x1)=f(x2) implies x1=x2; onto (surjective) if every element of B has a preimage; bijective if both. A function is invertible iff it is bijective; f^-1(y) = x means f(x)=y. gof exists when codomain of f equals domain of g. Composite functions: (gof)(x) = g(f(x)); composition is associative but not commutative. Binary operation * on set S maps S x S to S; examples on R: +, -, x, division is not a binary operation on R because 1/0 undefined; * defined by a*b = ab/4 on R\{0} is associative; identity element e satisfies a*e = e*a = a; a has inverse b if a*b = b*a = e.

CHAPTER 2: INVERSE TRIGONOMETRIC FUNCTIONS
Domain of sin^-1 x is [-1,1], principal value range is [-pi/2, pi/2]. cos^-1 x range [0, pi]. tan^-1 x range (-pi/2, pi/2). cot^-1 x range (0, pi). sec^-1 x range [0, pi] excluding pi/2. cosec^-1 x range [-pi/2, pi/2] excluding 0. sin^-1(sin x) = x only for x in the principal branch. Principal values: sin^-1(1/2) = pi/6, cos^-1(-1/2) = 2pi/3, tan^-1(-1) = -pi/4, sin^-1(1/sqrt2) = pi/4. Properties: sin^-1 x + cos^-1 x = pi/2; tan^-1 x + cot^-1 x = pi/2; sec^-1 x + cosec^-1 x = pi/2. tan^-1 x + tan^-1 y = tan^-1[(x+y)/(1-xy)] when xy < 1; = pi + tan^-1[(x+y)/(1-xy)] when xy > 1, x>0, y>0. 2 tan^-1 x = sin^-1[2x/(1+x^2)] = cos^-1[(1-x^2)/(1+x^2)] = tan^-1[2x/(1-x^2)]. For example solve tan^-1 x + tan^-1(1/x) = pi/2 for x>0.

CHAPTER 3: MATRICES
A matrix is a rectangular array of numbers; order m x n means m rows and n columns. Types: row matrix (1 x n), column (m x 1), square, diagonal, scalar, identity I, zero matrix, upper/lower triangular. Two matrices are equal if same order and corresponding elements equal. Addition/subtraction only for same order; kA multiplies every element. Matrix multiplication: AB defined only if number of columns of A = number of rows of B; (AB)_ij = sum_k A_ik B_kj; multiplication not commutative; AB = 0 does not imply A=0 or B=0; (AB)C = A(BC) associative; A(B+C) = AB + AC distributive. Transpose: (A')' = A; (A+B)' = A' + B'; (AB)' = B'A'. A is symmetric if A = A', skew-symmetric if A = -A'. Every square matrix = P + Q where P = (A + A')/2 symmetric, Q = (A - A')/2 skew-symmetric. Elementary row/column operations: R_i <-> R_j, R_i -> kR_i, R_i -> R_i + kR_j. Invertible matrix: A^-1 exists iff |A| not equal to 0; A^-1 = adj(A)/|A| for square A; (AB)^-1 = B^-1 A^-1. Example: for A = [[1,2],[3,4]], adj(A) = [[4,-2],[-3,1]], |A| = -2, A^-1 = [[-2,1],[3/2,-1/2]].

CHAPTER 4: DETERMINANTS
For 2x2 matrix [[a,b],[c,d]] determinant = ad - bc. For 3x3, expand along any row/column using minors and cofactors; cofactor C_ij = (-1)^(i+j) M_ij. Properties: |A'| = |A|; if two rows/columns identical or proportional determinant is zero; interchanging two rows changes sign; multiplying a row by k multiplies determinant by k; if a row is a sum of two rows, determinant splits as sum; elementary row operations R_i -> R_i + kR_j leave determinant unchanged. adj(adj(A)) = |A|^(n-2) A for n x n. |adj A| = |A|^(n-1). A(adj A) = (adj A) A = |A| I. If |A| = 0, A is singular, inverse does not exist. Area of triangle with vertices (x1,y1),(x2,y2),(x3,y3) = (1/2)|x1(y2-y3) + x2(y3-y1) + x3(y1-y2)|. System of equations: consistent (unique solution if |A| not 0, x = A^-1 B), or inconsistent/infinite solutions when |A| = 0. Cramer's rule for 2 variables: x = D1/D, y = D2/D. Collinear points give zero area.

CHAPTER 5: CONTINUITY AND DIFFERENTIABILITY
f is continuous at x = a if limit x->a f(x) = f(a). Polynomials, rational functions (where denominator nonzero), trig, exponential, log functions are continuous on their domains. Differentiability implies continuity, converse false (e.g., |x| continuous but not differentiable at 0). Standard derivatives: d/dx (x^n) = n x^(n-1); d/dx sin x = cos x; d/dx cos x = -sin x; d/dx tan x = sec^2 x; d/dx e^x = e^x; d/dx log x = 1/x; d/dx (a^x) = a^x log a. Chain rule: dy/dx = (dy/du)(du/dx). Logarithmic differentiation for y = u^v form: take log both sides, differentiate. Parametric: if x = f(t), y = g(t) then dy/dx = (dy/dt)/(dx/dt). Implicit functions: differentiate both sides w.r.t. x, treating y as function of x. Second order derivative d^2y/dx^2 = d/dx(dy/dx). Rolle's theorem: f continuous on [a,b], differentiable (a,b), f(a) = f(b) => exists c in (a,b) with f'(c) = 0. Lagrange Mean Value Theorem: exists c with f'(c) = (f(b)-f(a))/(b-a).

CHAPTER 6: APPLICATION OF DERIVATIVES
dy/dx gives rate of change; if y = x^3 then dy/dt = 3x^2 dx/dt. Increasing: f'(x) > 0 on interval; decreasing if f'(x) < 0. Tangents: slope of tangent = dy/dx at point; equation of tangent y - y0 = m(x - x0); normal slope = -1/m. Maxima/minima: local max if f'(x) = 0 and f''(x) < 0; local min if f''(x) > 0. Absolute maxima/minima on closed interval found by evaluating at critical points and endpoints. First derivative test: sign change of f'. Example: find the maximum area of a rectangle with perimeter P -> square. A wire of length 36 m bent to form rectangle: max area when square of side 9. Example: show f(x) = x^3 - 3x^2 + 3x - 100 is increasing for all real x (f' = 3(x-1)^2 >= 0). Maximum value of sin x + cos x on [0, pi/2] is sqrt 2 at x = pi/4.

CHAPTER 7: INTEGRALS
Integration is inverse of differentiation. Integral of x^n dx = x^(n+1)/(n+1) + C (n not -1). Integral 1/x dx = log|x| + C. Integral e^x dx = e^x + C. Integral sin x dx = -cos x + C; cos x -> sin x; sec^2 x -> tan x; sec x tan x -> sec x; 1/sqrt(1-x^2) -> sin^-1 x; 1/(1+x^2) -> tan^-1 x. Properties: integral k f(x) dx = k integral f(x) dx; integral (f + g) = sum. Substitution: integral f(g(x)) g'(x) dx = integral f(u) du with u = g(x). Integration by parts: integral u v dx = u integral v dx - integral (u' integral v dx) dx; choose u by ILATE order. Partial fractions for rational functions: forms A/(x-a), A/((x-a)^2), (Ax+B)/(x^2 + px + q). Definite integrals: integral a to b f(x) dx = F(b) - F(a). Properties: integral a to b f = integral a to b f(a+b-x); integral 0 to a f(x) = integral 0 to a f(a-x); integral -a to a f(x) dx = 2 integral 0 to a f(x) if f even, 0 if f odd; integral a to b f = integral a to c f + integral c to b f. Example: integral 0 to pi/2 log(sin x) dx = -(pi/2) log 2. Integral 0 to 1 sqrt((1-x)/(1+x)) dx = pi/2 - 1. Integral dx/(x^2 - a^2) = (1/2a) log|(x-a)/(x+a)|.

CHAPTER 8: APPLICATION OF INTEGRALS
Area bounded by curve y = f(x), x-axis and lines x = a, x = b is integral a to b f(x) dx (if f >= 0). Area between two curves y = f(x) and y = g(x) from a to b is integral a to b |f(x) - g(x)| dx. Example: area of circle x^2 + y^2 = a^2 is pi a^2 (by integration: 4 integral 0 to a sqrt(a^2 - x^2) dx = pi a^2). Area of ellipse x^2/a^2 + y^2/b^2 = 1 is pi ab. Area between parabola y^2 = 4ax and line x = a is (8/3) a^2. Area bounded by y = x^2 and y = |x|: intersection at x = 1; area = 1/3.

CHAPTER 9: DIFFERENTIAL EQUATIONS
Differential equation: equation involving derivatives. Order = highest derivative order; degree = power of highest derivative (after removing radicals). General vs particular solution. Variable separable: dy/dx = g(x) h(y) -> integral dy/h(y) = integral g(x) dx. Homogeneous: dy/dx = F(y/x); substitute y = vx, dy/dx = v + x dv/dx. Linear: dy/dx + P(x) y = Q(x); integrating factor IF = e^(integral P dx); solution y(IF) = integral Q (IF) dx + C. Example: solve dy/dx = 2xy -> y = C e^(x^2). Example: order of (d^2y/dx^2)^3 + (dy/dx)^2 + sin y = 0 is 2, degree 3. Rate problems: population growth dP/dt = kP; radioactive decay; Newton's cooling.

CHAPTER 10: VECTOR ALGEBRA
Vector has magnitude and direction; position vector of point P(x,y,z) = x i + y j + z k. Magnitude |a| = sqrt(x^2 + y^2 + z^2). Direction cosines l = x/|a|, m = y/|a|, n = z/|a|, with l^2 + m^2 + n^2 = 1. Unit vector = a/|a|. Scalar (dot) product: a.b = |a||b| cos theta = a1b1 + a2b2 + a3b3; a.b = 0 iff perpendicular. Projection of a on b = a.b/|b|. Vector (cross) product: a x b = |a||b| sin theta n-hat; magnitude = area of parallelogram; direction by right-hand rule; i x j = k, j x k = i, k x i = j; a x a = 0; a x b perpendicular to both a and b. Scalar triple product [a b c] = a.(b x c) gives volume of parallelepiped; coplanar iff zero. For vectors 2i + 3j + 4k and i + j + k: angle between them cos theta = 9/(sqrt29 sqrt3).

CHAPTER 11: THREE DIMENSIONAL GEOMETRY
Direction cosines l, m, n of a line with direction ratios a, b, c: l = a/sqrt(a^2+b^2+c^2) etc. Equation of line through point (x1,y1,z1) with direction ratios a,b,c: (x-x1)/a = (y-y1)/b = (z-z1)/c. Vector form: r = a + lambda b. Angle between two lines: cos theta = |b1.b2|/(|b1||b2|). Lines perpendicular iff a1a2 + b1b2 + c1c2 = 0. Shortest distance between skew lines; distance between parallel lines = |(a2-a1) x b|/|b|. Plane: normal form r.n = d; general ax + by + cz + d = 0; intercept form x/a + y/b + z/c = 1; plane through three points. Angle between two planes: angle between normals. Angle between line and plane: sin theta = |b.n|/(|b||n|). Distance of point (x1,y1,z1) from plane ax + by + cz + d = 0: |ax1 + by1 + cz1 + d|/sqrt(a^2 + b^2 + c^2). Planes x + y + z = 1 and x + y + z = 3 are parallel, distance = 2/sqrt3.

CHAPTER 12: LINEAR PROGRAMMING
LPP: optimize (maximize or minimize) linear objective function Z = ax + by subject to linear constraints (inequalities). Feasible region = intersection of half-planes; corner points = vertices. Theorem: optimal value (if finite) occurs at a corner point of the feasible region. Unbounded feasible region: check if value is maximum/minimum by considering whether region can be extended (e.g., check value at large test point). Example: maximize Z = 3x + 4y subject to x + y <= 4, x >= 0, y >= 0. Corner points (0,0), (4,0), (0,4): Z = 0, 12, 16 -> maximum 16 at (0,4). Example: minimize Z = x + 2y subject to 2x + y >= 3, x + 2y >= 6, x, y >= 0: minimum 6 at (0,3) and (6,0).

CHAPTER 13: PROBABILITY
Conditional probability P(A|B) = P(A and B)/P(B). Multiplication theorem: P(A and B) = P(A) P(B|A). Independent events: P(A and B) = P(A)P(B). Partition theorem (total probability): P(A) = sum P(A|E_i) P(E_i). Bayes' theorem: P(E_i|A) = P(A|E_i)P(E_i) / sum P(A|E_j)P(E_j) - used to find reverse conditional probabilities, e.g., a bag contains 4 red 3 black balls, another 5 red 6 black; probability a red ball drawn came from a given bag. Random variable X with distribution P(X = xi) = pi, sum pi = 1. Mean E(X) = sum xi pi. Variance Var(X) = sum xi^2 pi - (E(X))^2 = E(X^2) - (E(X))^2. Bernoulli trials: independent trials with two outcomes, constant probability. Binomial distribution: P(X = r) = C(n,r) p^r q^(n-r), q = 1 - p, for n trials; mean = np, variance = npq. Example: probability of exactly 2 heads in 5 tosses of fair coin = C(5,2)(1/2)^5 = 10/32 = 5/16. Example: probability at least one head in 2 tosses = 1 - (1/4) = 3/4.
