## 3. Streams & Level-Matched Questions

Each stream gets **its own question banks at its own difficulty** — no baby questions, only questions that stream-level student can actually solve.

| Stream | Difficulty Mix | Example of level-appropriate question |
|--------|----------------|--------------------------------------|
| **JEE Advanced** | Hard (60%) / Medium (40%) | Multi-concept physics, calculus + geometry combo |
| **JEE Mains** | Medium (60%) / Hard (20%) / Easy (20%) | NCERT-level with tricky twists, standard JEE patterns |
| **NEET** | Medium (50%) / Easy (50%) | NCERT-based biology/physics, assertion-reason |
| **CBSE 10** | Medium (40%) / Easy (60%) | Board-pattern: quadratic equations, carbon compounds |
| **CBSE 9** | Medium (35%) / Easy (65%) | Motion, matter around us, number systems |
| **CBSE 8** | Easy (70%) / Medium (30%) | Linear equations, cell structure, light |

- Diagnostic = **50 questions**, mixed across subjects, auto-graded, level-matched to the chosen stream.
- Mock tests generated by `mimo-v2.5-free` sit **within the stream's difficulty band** — never below it.
